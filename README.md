# 💖 Do You Love Me? Animation

A playful and interactive Valentine's Day web project that asks "Do you love me?" with fun animations and interactive buttons.

## ✨ Features

- Interactive "Yes" and "No" buttons
- The "No" button playfully dodges the cursor
- Heart loading animation
- Romantic video backgrounds
- Smooth CSS animations and transitions
- Fully responsive design

## 🚀 Live Demo

Open `index.html` in your browser to see the project in action!

## 📁 Project Structure

```
├── index.html      # Main HTML file
├── style.css       # All styling and animations
├── script.js       # Interactive functionality
├── Love me.mp4     # Result video
└── Reply me love.mp4  # Background video
```

## 💻 Technologies Used

- HTML5
- CSS3 (Animations, Keyframes, Flexbox)
- JavaScript (DOM Manipulation, Event Listeners)

## 🎯 How It Works

1. The page displays a romantic question with two buttons
2. Hovering over the "No" button makes it dodge your cursor
3. Clicking "Yes" triggers a heart loading animation
4. After loading, a sweet message with video appears

## 📱 Responsive Design

Works beautifully on desktop, tablet, and mobile devices.
