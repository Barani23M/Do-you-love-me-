# Do You Love Me? 💕

An interactive Valentine's Day website with a playful twist!

## Features

- 🎨 Beautiful purple gradient background
- 💕 Animated floating hearts
- 🎭 Interactive buttons with playful behavior
- 💖 Romantic success message
- 📱 Fully responsive design

## How to Use

1. Simply open `index.html` in your web browser
2. Answer the question "Do You Love Me?"
3. Try clicking the "No" button... if you dare! 😉
4. Click "Yes" to see a sweet surprise!

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and animations
- `script.js` - Interactive functionality

## Demo

When you try to click "No", the button moves away! The "Yes" button grows larger with each attempt, encouraging the right choice. 💖

Perfect for Valentine's Day or any romantic occasion! 🌹
